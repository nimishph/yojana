# review-document

The first template: a long document with an outline and a review rail. Planned files:

- `template.json` — manifest (parts, actions, tokens, schema)
- `page.html` — top bar, outline, document, rail
- `parts/section.html`, `parts/outline-item.html`, `parts/thread.html`, `parts/change.html`,
  `parts/activity.html`, `parts/forms/*.html`
- `content.schema.json`
- `theme.css` — default tokens, light and dark

The layout is specified in ../../docs/design.md and the yojana review-surface design proposal.
